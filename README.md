# Project Apex Loader
The repository of the Project Apex Loader.

# What is Project Apex?
Project Apex is a ROBLOX Script that the user runs in a executor. There is some games that are supported for Project Apex, Project Apex will be adding new games for user's to use.
With Project Apex you can do things that in ROBLOX are normally impossible, things like Fly, Noclip (pass trough walls), Change you walkspeed and much more that others cant do.
